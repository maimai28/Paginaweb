Potencias, sumas y constantes

ReglaFórmula
Constante$(c)' = 0$
Potencia (cualquier $n$ real)$(x^n)' = n\,x^{n - 1}$
Múltiplo constante$(c\,f)' = c\,f'$
Suma y resta$(f \pm g)' = f' \pm g'$
1
Ejemplo resuelto

Deriva $y = 4x^5 - 3x^2 + 7x - 2$.

$$y' = 20x^4 - 6x + 7$$

Para usar la regla de la potencia, escribe primero las raíces y las $x$ del denominador como potencias: $\sqrt{x} = x^{1/2}$, $\dfrac{1}{x^3} = x^{-3}$.

2
Ejemplo resuelto

Deriva $y = \dfrac{3}{x^2} + \sqrt{x}$.

$$y = 3x^{-2} + x^{1/2} \;\Rightarrow\; y' = -6x^{-3} + \tfrac{1}{2}x^{-1/2} = -\frac{6}{x^3} + \frac{1}{2\sqrt{x}}$$

Producto y cociente

Reglas del producto y del cociente $$(f\,g)' = f'g + f\,g' \qquad\qquad \left(\frac{f}{g}\right)' = \frac{f'g - f\,g'}{g^2}$$

La derivada de un producto no es el producto de las derivadas. En el cociente el orden importa por el signo menos: empieza derivando el de arriba.

3
Ejemplo resuelto

Deriva $y = x^2\sin x$.

$$y' = 2x\sin x + x^2\cos x$$
4
Ejemplo resuelto

Deriva $y = \dfrac{x^2 + 1}{x - 3}$.

$$y' = \frac{2x(x - 3) - (x^2 + 1)(1)}{(x - 3)^2} = \frac{x^2 - 6x - 1}{(x - 3)^2}$$
Antes de usar el cociente, ¿se puede simplificar?

$\dfrac{x^3 - 2x}{x} = x^2 - 2$ (para $x \neq 0$) se deriva en un paso. Y $\dfrac{5}{x^4} = 5x^{-4}$ no necesita la regla del cociente.

5
Ejemplo resuelto

Comprueba que $(\tan x)' = \sec^2 x$ con la regla del cociente.

$$\left(\frac{\sin x}{\cos x}\right)' = \frac{\cos x\cos x - \sin x(-\sin x)}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{1}{\cos^2 x} = \sec^2 x$$
6
Ejemplo resuelto

Deriva $y = e^x\ln x$.

$$y' = e^x\ln x + e^x\cdot\frac{1}{x} = e^x\left(\ln x + \frac{1}{x}\right)$$

Derivadas superiores y movimiento

La segunda derivada $f''$ es la derivada de $f'$. Si $s(t)$ es la posición, entonces $v(t) = s'(t)$ es la velocidad y $a(t) = v'(t) = s''(t)$ es la aceleración.

7
Ejemplo resuelto

Un móvil tiene $s(t) = t^3 - 6t^2$ metros. Encuentra velocidad y aceleración en $t = 3$ s.

$$v(t) = 3t^2 - 12t \qquad a(t) = 6t - 12$$

En $t = 3$: $v = 27 - 36 = -9$ m/s (se mueve hacia atrás) y $a = 6$ m/s² (está frenando ese retroceso).

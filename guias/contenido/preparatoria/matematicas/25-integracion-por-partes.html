La fórmula

Integra la regla del producto $(uv)' = u'v + uv'$ y despeja:

Integración por partes $$\int u\,dv = uv - \int v\,du$$

Se elige una parte del integrando como $u$ (que vas a derivar) y el resto como $dv$ (que vas a integrar). Funciona si la nueva integral $\int v\,du$ es más fácil que la original.

1
Ejemplo resuelto

Calcula $\displaystyle\int x\,e^x\,dx$.

$u = x$ (al derivarla desaparece) y $dv = e^x\,dx$. Entonces $du = dx$ y $v = e^x$:

$$\int x\,e^x\,dx = x\,e^x - \int e^x\,dx = x\,e^x - e^x + C$$

Comprueba: $(xe^x - e^x)' = e^x + xe^x - e^x = xe^x$ ✔

Cómo elegir $u$

Una guía práctica es la regla LIATE: toma como $u$ la función que aparezca primero en esta lista.

IInversas trigonométricas$\arctan x$, $\arcsin x$

2
Ejemplo resuelto

Calcula $\displaystyle\int x\cos x\,dx$.

A antes que T: $u = x$, $dv = \cos x\,dx$, $du = dx$, $v = \sin x$.

$$\int x\cos x\,dx = x\sin x - \int\sin x\,dx = x\sin x + \cos x + C$$

Si hubieras elegido $u = \cos x$, la nueva integral tendría $x^2$: peor que al inicio.

Funciones solas: $\ln x$ y $\arctan x$

No hay fórmula de tabla para $\int\ln x\,dx$. El truco: $u = \ln x$ y $dv = dx$.

3
Ejemplo resuelto

Calcula $\displaystyle\int\ln x\,dx$.

$u = \ln x$, $du = \tfrac{1}{x}dx$, $v = x$:

$$\int\ln x\,dx = x\ln x - \int x\cdot\frac{1}{x}\,dx = x\ln x - x + C$$

Partes repetidas: método tabular

Con $x^n$ por una exponencial o una trigonométrica, hay que aplicar partes $n$ veces. El método tabular lo organiza: en una columna derivas $u$ hasta llegar a cero; en otra integras $dv$ las mismas veces; multiplicas en diagonal con signos alternados $+, -, +, \ldots$

4
Ejemplo resuelto

Calcula $\displaystyle\int x^2e^x\,dx$.

$$\int x^2e^x\,dx = x^2e^x - 2xe^x + 2e^x + C = e^x(x^2 - 2x + 2) + C$$

Integrales cíclicas

Con $e^x$ por seno o coseno, las derivadas nunca llegan a cero. Aplica partes dos veces: reaparece la integral original y la despejas como en una ecuación.

5
Ejemplo resuelto

Calcula $I = \displaystyle\int e^x\sin x\,dx$.

Primera vez, $u = \sin x$, $dv = e^x dx$: $I = e^x\sin x - \int e^x\cos x\,dx$.

Segunda vez, $u = \cos x$: $\int e^x\cos x\,dx = e^x\cos x + \int e^x\sin x\,dx = e^x\cos x + I$.

$$I = e^x\sin x - e^x\cos x - I \;\Rightarrow\; I = \frac{e^x(\sin x - \cos x)}{2} + C$$
6
Ejemplo resuelto

Calcula $\displaystyle\int_0^\pi x\sin x\,dx$.

Por partes, $\int x\sin x\,dx = -x\cos x + \sin x$. Evalúa:

$$\Big[-x\cos x + \sin x\Big]_0^\pi = (-\pi\cos\pi + 0) - 0 = \pi$$

Soluciones paso a paso

1

3
L antes que A: $u = \ln x$, $v = \tfrac{x^2}{2}$. Queda $\int\tfrac{x^2}{2}\cdot\tfrac{1}{x}dx = \tfrac{x^2}{4}$.
4
$u = \arctan x$, $dv = dx$: $x\arctan x - \int\dfrac{x}{1 + x^2}dx$; la última es sustitución.
5
$u = x$, $v = \tan x$: $x\tan x - \int\tan x\,dx = x\tan x + \ln|\cos x|$.
6
Tabular: $x^2, 2x, 2, 0$ con $\sin x, -\cos x, -\sin x$ y signos $+, -, +$.
7
Tabular: $x^3, 3x^2, 6x, 6$ con $e^x$ y signos alternados.
8
$u = (\ln x)^2$, $v = x$: $x(\ln x)^2 - \int 2\ln x\,dx$, y usa el ejemplo 3.
9
$I = e^x\cos x + \int e^x\sin x = e^x\cos x + e^x\sin x - I$.
10
Con $u$ trigonométrica: $I = \tfrac{1}{2}e^{2x}\sin x - \tfrac{1}{2}\left(\tfrac{1}{2}e^{2x}\cos x + \tfrac{1}{2}I\right)$, así que $\tfrac{5}{4}I = \tfrac{1}{2}e^{2x}\sin x - \tfrac{1}{4}e^{2x}\cos x$.

12

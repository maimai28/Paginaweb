Factores lineales distintos

Si el denominador se factoriza en factores lineales distintos, la fracción se separa en una por cada factor:

$$\frac{P(x)}{(x - a)(x - b)} = \frac{A}{x - a} + \frac{B}{x - b}$$

Para encontrar $A$ y $B$: multiplica todo por el denominador y sustituye las raíces; cada una elimina todas las constantes menos una.

1
Ejemplo resuelto

Calcula $\displaystyle\int\frac{5x - 1}{x^2 - 1}\,dx$.

$x^2 - 1 = (x - 1)(x + 1)$. Plantea $5x - 1 = A(x + 1) + B(x - 1)$.

Con $x = 1$: $4 = 2A$, $A = 2$. Con $x = -1$: $-6 = -2B$, $B = 3$.

$$\int\left(\frac{2}{x - 1} + \frac{3}{x + 1}\right)dx = 2\ln|x - 1| + 3\ln|x + 1| + C$$
2
Ejemplo resuelto

Calcula $\displaystyle\int\frac{dx}{x^2 - 4}$.

$1 = A(x + 2) + B(x - 2)$: con $x = 2$, $A = \tfrac{1}{4}$; con $x = -2$, $B = -\tfrac{1}{4}$.

$$\frac{1}{4}\ln|x - 2| - \frac{1}{4}\ln|x + 2| + C = \frac{1}{4}\ln\left|\frac{x - 2}{x + 2}\right| + C$$
Antes, revisa si es una sustitución

En $\displaystyle\int\frac{2x}{x^2 - 1}\,dx$ el numerador es la derivada del denominador: sale $\ln|x^2 - 1| + C$ directamente, sin fracciones parciales.

Factores repetidos

Si un factor aparece elevado a una potencia, lleva una fracción por cada potencia, desde 1 hasta la mayor:

$$\frac{P(x)}{(x - a)^2} = \frac{A}{x - a} + \frac{B}{(x - a)^2}$$
3
Ejemplo resuelto

Calcula $\displaystyle\int\frac{x + 3}{(x - 1)^2}\,dx$.

$x + 3 = A(x - 1) + B$. Con $x = 1$: $B = 4$. Comparando el coeficiente de $x$: $A = 1$.

$$\int\left(\frac{1}{x - 1} + \frac{4}{(x - 1)^2}\right)dx = \ln|x - 1| - \frac{4}{x - 1} + C$$

Cuando sustituir raíces no alcanza para todas las constantes, iguala coeficientes de las mismas potencias de $x$, o sustituye cualquier otro valor cómodo (como $x = 0$).

Factores cuadráticos irreducibles

Un factor como $x^2 + 1$ (que no tiene raíces reales) lleva un numerador lineal:

$$\frac{P(x)}{x(x^2 + 1)} = \frac{A}{x} + \frac{Bx + C}{x^2 + 1}$$

Y se integra separando: $\displaystyle\int\frac{x}{x^2 + 1}dx = \tfrac{1}{2}\ln(x^2 + 1)$ y $\displaystyle\int\frac{1}{x^2 + 1}dx = \arctan x$.

4
Ejemplo resuelto

Calcula $\displaystyle\int\frac{dx}{x(x^2 + 1)}$.

$1 = A(x^2 + 1) + (Bx + C)x$. Con $x = 0$: $A = 1$. Coeficiente de $x^2$: $A + B = 0$, $B = -1$. Coeficiente de $x$: $C = 0$.

$$\int\left(\frac{1}{x} - \frac{x}{x^2 + 1}\right)dx = \ln|x| - \frac{1}{2}\ln(x^2 + 1) + C$$

Fracciones impropias

Si el grado del numerador es mayor o igual que el del denominador, primero divide (división larga o sintética). Queda un polinomio más una fracción propia.

5
Ejemplo resuelto

Calcula $\displaystyle\int\frac{x^2 + 1}{x^2 - 1}\,dx$.

Mismo grado: $\dfrac{x^2 + 1}{x^2 - 1} = 1 + \dfrac{2}{x^2 - 1} = 1 + \dfrac{1}{x - 1} - \dfrac{1}{x + 1}$.

$$x + \ln|x - 1| - \ln|x + 1| + C$$

Ejercicios

Comprueba cada descomposición sumando las fracciones. Al final encontrarás las respuestas y las soluciones paso a paso.

A. Lineales distintos

  1. $\displaystyle\int\frac{dx}{x(x + 2)}$
  2. $\displaystyle\int\frac{3x + 5}{(x + 1)(x + 3)}\,dx$
  3. $\displaystyle\int\frac{x + 7}{x^2 - x - 6}\,dx$
  4. $\displaystyle\int\frac{2x}{x^2 - 1}\,dx$

B. Repetidos

  1. $\displaystyle\int\frac{2x + 1}{(x + 1)^2}\,dx$
  2. $\displaystyle\int\frac{dx}{x^2(x - 1)}$

C. Cuadráticos

  1. $\displaystyle\int\frac{2x + 3}{x^2 + 1}\,dx$
  2. $\displaystyle\int\frac{x^2 + 2}{x(x^2 + 1)}\,dx$

D. Impropias y definidas

  1. $\displaystyle\int\frac{x^2}{x + 1}\,dx$
  2. $\displaystyle\int_2^3\frac{dx}{x^2 - 1}$
  3. $\displaystyle\int_0^1\frac{dx}{(x + 1)(x + 2)}$

Respuestas y soluciones

  1. $\tfrac{1}{2}\ln|x| - \tfrac{1}{2}\ln|x + 2| + C$
  2. $\ln|x + 1| + 2\ln|x + 3| + C$
  3. $2\ln|x - 3| - \ln|x + 2| + C$
  4. $\ln|x^2 - 1| + C$
  5. $2\ln|x + 1| + \dfrac{1}{x + 1} + C$
  6. $-\ln|x| + \dfrac{1}{x} + \ln|x - 1| + C$
  7. $\ln(x^2 + 1) + 3\arctan x + C$
  8. $2\ln|x| - \tfrac{1}{2}\ln(x^2 + 1) + C$
  9. $\tfrac{x^2}{2} - x + \ln|x + 1| + C$
  10. $\tfrac{1}{2}\ln\tfrac{3}{2} \approx 0.203$
  11. $\ln\tfrac{4}{3} \approx 0.288$

Soluciones paso a paso

1
$1 = A(x + 2) + Bx$: $x = 0 \Rightarrow A = \tfrac{1}{2}$; $x = -2 \Rightarrow B = -\tfrac{1}{2}$.
2
$3x + 5 = A(x + 3) + B(x + 1)$: $x = -1 \Rightarrow 2 = 2A$; $x = -3 \Rightarrow -4 = -2B$.
3
$x^2 - x - 6 = (x - 3)(x + 2)$. $x = 3 \Rightarrow 10 = 5A$; $x = -2 \Rightarrow 5 = -5B$.
4
Sustitución $u = x^2 - 1$. Por fracciones parciales sale $\ln|x - 1| + \ln|x + 1|$, que es lo mismo.
5
$2x + 1 = 2(x + 1) - 1$: $\dfrac{2}{x + 1} - \dfrac{1}{(x + 1)^2}$.
6
$1 = Ax(x - 1) + B(x - 1) + Cx^2$: $x = 0 \Rightarrow B = -1$; $x = 1 \Rightarrow C = 1$; coeficiente de $x^2$: $A + C = 0$.
7
Ya está separada: $\dfrac{2x}{x^2 + 1} + \dfrac{3}{x^2 + 1}$.
8
$x^2 + 2 = A(x^2 + 1) + (Bx + C)x$: $x = 0 \Rightarrow A = 2$; $x^2$: $A + B = 1 \Rightarrow B = -1$; $x$: $C = 0$.
9
Divide: $x^2 = (x + 1)(x - 1) + 1$, así que $\dfrac{x^2}{x + 1} = x - 1 + \dfrac{1}{x + 1}$.
10
$\tfrac{1}{2}\left[\ln\left|\tfrac{x - 1}{x + 1}\right|\right]_2^3 = \tfrac{1}{2}\left(\ln\tfrac{1}{2} - \ln\tfrac{1}{3}\right)$.
11
$\dfrac{1}{x + 1} - \dfrac{1}{x + 2}$: $[\ln(x + 1) - \ln(x + 2)]_0^1 = (\ln 2 - \ln 3) + \ln 2$.

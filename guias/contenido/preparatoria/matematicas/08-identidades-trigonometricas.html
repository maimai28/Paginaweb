Identidades fundamentales

TipoIdentidades
Recíprocas$\csc x = \dfrac{1}{\sin x}$, $\ \sec x = \dfrac{1}{\cos x}$, $\ \cot x = \dfrac{1}{\tan x}$
De cociente$\tan x = \dfrac{\sin x}{\cos x}$, $\ \cot x = \dfrac{\cos x}{\sin x}$
Pitagóricas$\sin^2 x + \cos^2 x = 1$, $\ 1 + \tan^2 x = \sec^2 x$, $\ 1 + \cot^2 x = \csc^2 x$
Paridad$\sin(-x) = -\sin x$, $\ \cos(-x) = \cos x$, $\ \tan(-x) = -\tan x$
Solo necesitas memorizar una pitagórica

Divide $\sin^2 x + \cos^2 x = 1$ entre $\cos^2 x$ y obtienes $\tan^2 x + 1 = \sec^2 x$. Divide entre $\sin^2 x$ y sale la tercera.

Simplificar

La estrategia que casi siempre funciona: pasa todo a senos y cosenos, junta fracciones y busca $\sin^2 x + \cos^2 x$.

1
Ejemplo resuelto

Simplifica $\sec x - \cos x$.

$$\frac{1}{\cos x} - \cos x = \frac{1 - \cos^2 x}{\cos x} = \frac{\sin^2 x}{\cos x} = \sin x\cdot\frac{\sin x}{\cos x} = \sin x\tan x$$

Demostrar identidades

Demostrar no es resolver una ecuación: no puedes pasar términos de un lado a otro, porque eso ya supone que la igualdad es cierta. El método correcto:

  1. Elige el lado más complicado.
  2. Transfórmalo con identidades y álgebra hasta que quede igual al otro lado.
  3. Ideas útiles: pasar a seno y coseno, sumar fracciones, factorizar, multiplicar por el conjugado.
2
Ejemplo resuelto

Demuestra que $(1 - \cos^2 x)(1 + \cot^2 x) = 1$.

Trabaja el lado izquierdo con las pitagóricas:

$$(1 - \cos^2 x)(1 + \cot^2 x) = \sin^2 x\cdot\csc^2 x = \sin^2 x\cdot\frac{1}{\sin^2 x} = 1 \quad \checkmark$$
3
Ejemplo resuelto

Demuestra que $\dfrac{\sin x}{1 + \cos x} = \dfrac{1 - \cos x}{\sin x}$.

Multiplica el lado izquierdo arriba y abajo por el conjugado $1 - \cos x$:

$$\frac{\sin x\,(1 - \cos x)}{(1 + \cos x)(1 - \cos x)} = \frac{\sin x\,(1 - \cos x)}{1 - \cos^2 x} = \frac{\sin x\,(1 - \cos x)}{\sin^2 x} = \frac{1 - \cos x}{\sin x} \quad \checkmark$$

4
Ejemplo resuelto

Calcula el valor exacto de $\sin 75^\circ$.

$$\sin(45^\circ + 30^\circ) = \frac{\sqrt{2}}{2}\cdot\frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2}\cdot\frac{1}{2} = \frac{\sqrt{6} + \sqrt{2}}{4} \approx 0.9659$$
5
Ejemplo resuelto

Si $\sin\theta = \tfrac{3}{5}$ y $\theta$ está en el cuadrante I, calcula $\sin 2\theta$ y $\cos 2\theta$.

Primero $\cos\theta = \tfrac{4}{5}$ (triángulo 3, 4, 5).

$$\sin 2\theta = 2\cdot\frac{3}{5}\cdot\frac{4}{5} = \frac{24}{25} \qquad\qquad \cos 2\theta = \frac{16}{25} - \frac{9}{25} = \frac{7}{25}$$

Ecuaciones con identidades

El objetivo es dejar una sola función de un solo ángulo. Si aparece $\sin 2x$ junto con $\sin x$, desarrolla el doble. Si aparecen $\sin^2 x$ y $\cos x$, cambia $\sin^2 x = 1 - \cos^2 x$. Luego factoriza.

6
Ejemplo resuelto

Resuelve $2\sin^2 x - \sin x - 1 = 0$ en $[0, 2\pi)$.

Es cuadrática en $\sin x$:

$$(2\sin x + 1)(\sin x - 1) = 0 \;\Rightarrow\; \sin x = -\tfrac{1}{2} \ \text{ o } \ \sin x = 1$$

Soluciones: $x = \dfrac{\pi}{2}$, $\dfrac{7\pi}{6}$ y $\dfrac{11\pi}{6}$.

No dividas entre $\sin x$

En $\sin 2x = \sin x$, dividir entre $\sin x$ pierde las soluciones donde $\sin x = 0$. Factoriza en su lugar: $\sin x\,(2\cos x - 1) = 0$.

La idea

Por la regla de la cadena, $\dfrac{d}{dx}F(g(x)) = F'(g(x))\,g'(x)$. Leída al revés:

Sustitución $$\int f\big(g(x)\big)\,g'(x)\,dx = \int f(u)\,du \qquad\text{con } u = g(x),\ du = g'(x)\,dx$$
  1. Elige $u$: normalmente la función «de adentro» (dentro de un paréntesis, una raíz, un exponente o un denominador).
  2. Calcula $du = u'\,dx$.
  3. Reescribe toda la integral en $u$; no debe quedar ninguna $x$.
  4. Integra y regresa a $x$.
1
Ejemplo resuelto

Calcula $\displaystyle\int 2x(x^2 + 1)^5\,dx$.

$u = x^2 + 1$, $du = 2x\,dx$. Justo lo que hay afuera del paréntesis:

$$\int u^5\,du = \frac{u^6}{6} + C = \frac{(x^2 + 1)^6}{6} + C$$

Ajustar constantes

Si a $du$ le falta solo un número, despéjalo: sale como factor de la integral. Si falta una $x$, no se puede ajustar así.

2
Ejemplo resuelto

Calcula $\displaystyle\int x\sqrt{x^2 + 4}\,dx$.

$u = x^2 + 4$, $du = 2x\,dx$, así que $x\,dx = \tfrac{1}{2}du$:

$$\frac{1}{2}\int u^{1/2}\,du = \frac{1}{2}\cdot\frac{u^{3/2}}{3/2} + C = \frac{1}{3}(x^2 + 4)^{3/2} + C$$

Un caso muy frecuente: si $u = ax + b$, entonces $du = a\,dx$ y basta dividir entre $a$. Por ejemplo, $\int\cos 3x\,dx = \tfrac{1}{3}\sin 3x + C$ y $\int e^{-2x}\,dx = -\tfrac{1}{2}e^{-2x} + C$.

Logaritmos y trigonométricas

Patrón del logaritmo $$\int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C$$

Si arriba está la derivada de lo de abajo (o un múltiplo), la respuesta es un logaritmo.

3
Ejemplo resuelto

Calcula $\displaystyle\int \tan x\,dx$ y $\displaystyle\int \frac{\ln x}{x}\,dx$.

$\tan x = \dfrac{\sin x}{\cos x}$; con $u = \cos x$, $du = -\sin x\,dx$:

$$\int \tan x\,dx = -\int\frac{du}{u} = -\ln|\cos x| + C$$

En la segunda, $u = \ln x$ y $du = \dfrac{dx}{x}$:

$$\int u\,du = \frac{(\ln x)^2}{2} + C$$

Integrales definidas

Al sustituir en una integral definida, cambia también los límites: si $x$ va de $a$ a $b$, $u$ va de $g(a)$ a $g(b)$. Así no tienes que regresar a $x$.

4
Ejemplo resuelto

Calcula $\displaystyle\int_0^1 x\,e^{x^2}\,dx$.

$u = x^2$, $du = 2x\,dx$. Límites: $x = 0 \to u = 0$; $x = 1 \to u = 1$.

$$\frac{1}{2}\int_0^1 e^u\,du = \frac{1}{2}\Big[e^u\Big]_0^1 = \frac{e - 1}{2} \approx 0.859$$

Cuando sobra una $x$

A veces, después de sustituir, queda una $x$ suelta. Si $u$ es lineal, despeja $x$ en términos de $u$ y sustitúyela.

5
Ejemplo resuelto

Calcula $\displaystyle\int \frac{x}{x + 1}\,dx$.

$u = x + 1$, $du = dx$ y $x = u - 1$:

$$\int \frac{u - 1}{u}\,du = \int\left(1 - \frac{1}{u}\right)du = u - \ln|u| + C = x + 1 - \ln|x + 1| + C$$

El 1 se puede absorber en la $C$: $x - \ln|x + 1| + C$ también es correcto.

Ejercicios

Comprueba derivando las indefinidas. Al final encontrarás las respuestas y las soluciones paso a paso.

A. Potencias y raíces

  1. $\displaystyle\int 3x^2(x^3 - 5)^4\,dx$
  2. $\displaystyle\int x(x^2 + 3)^7\,dx$
  3. $\displaystyle\int\sqrt{2x + 1}\,dx$
  4. $\displaystyle\int\frac{x}{\sqrt{x^2 + 9}}\,dx$
  5. $\displaystyle\int\frac{dx}{3x - 2}$

B. Trascendentes

  1. $\displaystyle\int\sin 5x\,dx$
  2. $\displaystyle\int x\cos(x^2)\,dx$
  3. $\displaystyle\int e^{4x}\,dx$
  4. $\displaystyle\int\frac{e^x}{1 + e^x}\,dx$
  5. $\displaystyle\int\sin x\cos^3 x\,dx$
  6. $\displaystyle\int\frac{(\ln x)^2}{x}\,dx$
  7. $\displaystyle\int\frac{dx}{1 + 4x^2}$

C. Definidas

  1. $\displaystyle\int_0^2 x(x^2 + 1)^2\,dx$
  2. $\displaystyle\int_0^{\pi/2}\sin x\cos x\,dx$
  3. $\displaystyle\int_1^e\frac{\ln x}{x}\,dx$
  4. $\displaystyle\int_0^1\frac{x}{x^2 + 1}\,dx$

D. Otros

  1. $\displaystyle\int x\sqrt{x - 1}\,dx$
  2. Una población crece a razón de $P'(t) = 200e^{0.05t}$ personas por año, con $P(0) = 4000$. ¿Cuántas habrá a los 10 años?

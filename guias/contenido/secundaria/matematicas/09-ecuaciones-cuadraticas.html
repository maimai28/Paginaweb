Qué es una ecuación cuadrática

Es una ecuación en la que la incógnita aparece elevada al cuadrado (y no a potencias mayores). Siempre se puede escribir en la forma general:

$$ax^2 + bx + c = 0 \qquad (a \neq 0)$$

Antes de resolver, pasa todo a un lado para que el otro quede en cero. Por ejemplo, $x^2 = 2x + 15$ se escribe $x^2 - 2x - 15 = 0$, con $a = 1$, $b = -2$ y $c = -15$.

¿Por qué puede haber dos soluciones?

Porque un número y su opuesto tienen el mismo cuadrado: $5^2 = 25$ y $(-5)^2 = 25$. Por eso $x^2 = 25$ tiene dos soluciones, $x = 5$ y $x = -5$.

Ecuaciones incompletas

Si falta el término $b$ o el término $c$, no necesitas fórmula.

Sin término en $x$: $ax^2 + c = 0$

Despeja $x^2$ y saca raíz. No olvides el $\pm$.

$$2x^2 - 50 = 0 \;\Rightarrow\; x^2 = 25 \;\Rightarrow\; x = \pm 5$$

Si te queda $x^2$ igual a un número negativo (como $x^2 = -4$), no hay solución real.

Sin término independiente: $ax^2 + bx = 0$

Saca factor común $x$. Una de las soluciones siempre es $x = 0$:

$$3x^2 - 12x = 0 \;\Rightarrow\; 3x(x - 4) = 0 \;\Rightarrow\; x = 0 \ \text{ o } \ x = 4$$

Resolver por factorización

Propiedad del producto cero

Si un producto vale cero, al menos uno de los factores vale cero: si $A\cdot B = 0$, entonces $A = 0$ o $B = 0$.

Por eso, si factorizas el lado izquierdo (con el derecho en cero), cada factor te da una solución.

1
Ejemplo resuelto

Resuelve $x^2 - 5x + 6 = 0$.

Dos números que multiplicados den 6 y sumados $-5$: son $-2$ y $-3$.

$$(x - 2)(x - 3) = 0 \;\Rightarrow\; x = 2 \ \text{ o } \ x = 3$$

Comprueba: $2^2 - 5(2) + 6 = 0$ ✔ y $3^2 - 5(3) + 6 = 0$ ✔.

Solo funciona con cero

La propiedad solo sirve si el otro lado es cero. Si tienes $(x - 2)(x - 3) = 2$, no puedes decir que $x - 2 = 2$: primero desarrolla, pasa el 2 al otro lado y vuelve a factorizar.

La fórmula general

Funciona para cualquier ecuación cuadrática, aunque no se pueda factorizar fácilmente:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

La expresión dentro de la raíz, $\Delta = b^2 - 4ac$, se llama discriminante y te dice cuántas soluciones hay antes de terminar la cuenta:

DiscriminanteSoluciones realesEjemplo
$\Delta \gt 0$Dos distintas$x^2 - 5x + 6 = 0$: $\Delta = 1$
$\Delta = 0$Una (repetida)$x^2 - 6x + 9 = 0$: $\Delta = 0$
$\Delta \lt 0$Ninguna$x^2 + 2x + 5 = 0$: $\Delta = -16$
2
Ejemplo resuelto

Resuelve $2x^2 + 3x - 2 = 0$.

Identifica $a = 2$, $b = 3$, $c = -2$. Discriminante: $\Delta = 3^2 - 4(2)(-2) = 9 + 16 = 25$.

$$x = \frac{-3 \pm \sqrt{25}}{2(2)} = \frac{-3 \pm 5}{4} \;\Rightarrow\; x = \frac{2}{4} = \frac{1}{2} \ \text{ o } \ x = \frac{-8}{4} = -2$$
3
Ejemplo resuelto

Resuelve $x^2 + 4x - 1 = 0$.

$\Delta = 16 + 4 = 20$ y $\sqrt{20} = 2\sqrt{5}$:

$$x = \frac{-4 \pm 2\sqrt{5}}{2} = -2 \pm \sqrt{5} \;\approx\; 0.24 \ \text{ o } \ -4.24$$

Problemas

En los problemas, revisa que la solución tenga sentido: una longitud o un tiempo no pueden ser negativos.

4
Ejemplo resuelto

Un terreno rectangular mide 3 m más de largo que de ancho y tiene 40 m² de área. ¿Cuánto mide?

$$x(x + 3) = 40 \;\Rightarrow\; x^2 + 3x - 40 = 0 \;\Rightarrow\; (x + 8)(x - 5) = 0$$

Las soluciones son $x = 5$ y $x = -8$, pero un ancho no puede ser negativo. El terreno mide 5 m por 8 m.

5
Ejemplo resuelto

Se lanza una pelota hacia arriba y su altura en metros es $h = 20t - 5t^2$ ($t$ en segundos). ¿Cuándo vuelve al suelo?

$$20t - 5t^2 = 0 \;\Rightarrow\; 5t(4 - t) = 0 \;\Rightarrow\; t = 0 \ \text{ o } \ t = 4$$

$t = 0$ es el momento del lanzamiento; vuelve al suelo a los 4 segundos.

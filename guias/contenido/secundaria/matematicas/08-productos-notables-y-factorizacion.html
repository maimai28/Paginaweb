Productos notables

Son multiplicaciones con una forma fija. Si reconoces la forma, escribes el resultado directo.

NombreFórmulaEjemplo
Binomio al cuadrado (suma)$(a + b)^2 = a^2 + 2ab + b^2$$(x + 5)^2 = x^2 + 10x + 25$
Binomio al cuadrado (resta)$(a - b)^2 = a^2 - 2ab + b^2$$(3x - 2)^2 = 9x^2 - 12x + 4$
Binomios conjugados$(a + b)(a - b) = a^2 - b^2$$(2x + 7)(2x - 7) = 4x^2 - 49$
Término común$(x + a)(x + b) = x^2 + (a + b)x + ab$$(x + 4)(x - 9) = x^2 - 5x - 36$
¿Por qué aparece el $2ab$?

Un cuadrado de lado $a + b$ se parte en cuatro piezas: un cuadrado $a^2$, un cuadrado $b^2$ y dos rectángulos de área $ab$. Por eso $(a + b)^2$ nunca es solo $a^2 + b^2$.

1
Ejemplo resuelto

Desarrolla $(3x - 2)^2$.

Aquí $a = 3x$ y $b = 2$. Cuadrado del primero, menos el doble del producto, más cuadrado del segundo:

$$(3x)^2 - 2(3x)(2) + 2^2 = 9x^2 - 12x + 4$$

Factor común

Factorizar es escribir una expresión como multiplicación. El primer paso, siempre, es buscar lo que se repite en todos los términos: el mayor número que divide a todos los coeficientes y cada letra con el menor exponente que aparezca.

2
Ejemplo resuelto

Factoriza $12a^3 + 18a^2$.

El mayor divisor de 12 y 18 es 6; la letra $a$ aparece con exponente 3 y 2, así que sale $a^2$. Divide cada término entre $6a^2$:

$$12a^3 + 18a^2 = 6a^2\,(2a + 3)$$

Comprueba multiplicando: $6a^2\cdot 2a + 6a^2\cdot 3 = 12a^3 + 18a^2$. ✔

Diferencia de cuadrados y trinomio cuadrado perfecto

Son los productos notables leídos al revés.

Diferencia de cuadrados $$a^2 - b^2 = (a + b)(a - b)$$

Se reconoce porque son dos términos, los dos cuadrados, restándose. Ejemplos: $x^2 - 49 = (x + 7)(x - 7)$ y $25 - 4y^2 = (5 + 2y)(5 - 2y)$.

Trinomio cuadrado perfecto $$a^2 \pm 2ab + b^2 = (a \pm b)^2$$

Se reconoce porque el primero y el último son cuadrados y el de en medio es el doble del producto de sus raíces. En $x^2 - 10x + 25$: $\sqrt{x^2} = x$, $\sqrt{25} = 5$ y $2\cdot x\cdot 5 = 10x$. ✔ Entonces $x^2 - 10x + 25 = (x - 5)^2$.

La suma de cuadrados no se factoriza

$x^2 + 9$ no es $(x + 3)(x - 3)$, porque eso da $x^2 - 9$. Con números reales, una suma de cuadrados no se puede factorizar.

Trinomios $x^2 + bx + c$

Busca dos números que multiplicados den $c$ y sumados den $b$. Si son $m$ y $n$:

$$x^2 + bx + c = (x + m)(x + n)$$
3
Ejemplo resuelto

Factoriza $x^2 + 7x + 12$ y $x^2 - 2x - 15$.

Para el primero: dos números que multiplicados den 12 y sumados 7 son 3 y 4.

$$x^2 + 7x + 12 = (x + 3)(x + 4)$$

Para el segundo: multiplicados $-15$ y sumados $-2$. Como el producto es negativo, tienen signos distintos: son $-5$ y $3$.

$$x^2 - 2x - 15 = (x - 5)(x + 3)$$
Cómo decidir qué hacer

1. Saca factor común si lo hay. 2. Cuenta los términos que quedan: si son dos, busca diferencia de cuadrados; si son tres, revisa si es cuadrado perfecto y, si no, busca los dos números. 3. Revisa si algún factor se puede factorizar otra vez. 4. Comprueba multiplicando.

4
Ejemplo resuelto

Factoriza por completo $2x^2 - 18$.

$$2x^2 - 18 = 2(x^2 - 9) = 2(x + 3)(x - 3)$$

Qué es una fracción

Una fracción $\dfrac{a}{b}$ indica que un entero se partió en $b$ partes iguales y se tomaron $a$ de ellas. El número de arriba es el numerador y el de abajo, el denominador (que nunca puede ser 0).

Fracciones equivalentes

Si multiplicas o divides el numerador y el denominador por el mismo número (distinto de cero), obtienes una fracción equivalente:

$$\frac{3}{4} = \frac{3\cdot 2}{4\cdot 2} = \frac{6}{8}$$

Simplificar es dividir arriba y abajo entre el mayor número que divida a ambos (el máximo común divisor):

$$\frac{18}{24} = \frac{18\div 6}{24\div 6} = \frac{3}{4}$$

Números mixtos

Una fracción con numerador mayor que el denominador se puede escribir como entero más fracción. Para pasar de mixto a fracción: multiplica el entero por el denominador y suma el numerador.

$$2\tfrac{1}{3} = \frac{2\cdot 3 + 1}{3} = \frac{7}{3} \qquad\qquad \frac{17}{5} = 3\tfrac{2}{5}\ \ \text{porque } 17 = 3\cdot 5 + 2$$

Suma y resta

Solo se pueden sumar fracciones que tengan el mismo denominador. En ese caso se suman los numeradores y el denominador se queda igual:

$$\frac{3}{8} + \frac{1}{8} = \frac{4}{8} = \frac{1}{2}$$

Si los denominadores son distintos, primero conviertes las dos fracciones a un denominador común. El más cómodo es el mínimo común múltiplo (mcm).

1
Ejemplo resuelto

Calcula $\dfrac{2}{3} + \dfrac{3}{4}$.

El mcm de 3 y 4 es 12. Convierte cada fracción y suma:

$$\frac{2}{3} + \frac{3}{4} = \frac{8}{12} + \frac{9}{12} = \frac{17}{12} = 1\tfrac{5}{12}$$
2
Ejemplo resuelto

Calcula $\dfrac{5}{6} - \dfrac{1}{4}$.

El mcm de 6 y 4 es 12:

$$\frac{5}{6} - \frac{1}{4} = \frac{10}{12} - \frac{3}{12} = \frac{7}{12}$$

Multiplicación y división

Multiplicar es más fácil que sumar: numerador por numerador y denominador por denominador. No necesitas denominador común.

$$\frac{a}{b}\cdot\frac{c}{d} = \frac{a\cdot c}{b\cdot d}$$

Para dividir, multiplica la primera fracción por el recíproco de la segunda (la segunda volteada):

$$\frac{a}{b}\div\frac{c}{d} = \frac{a}{b}\cdot\frac{d}{c}$$
3
Ejemplo resuelto

Calcula $\dfrac{2}{3}\cdot\dfrac{9}{10}$ y $\dfrac{3}{4}\div\dfrac{9}{8}$.

Simplifica antes de multiplicar para trabajar con números chicos:

$$\frac{2}{3}\cdot\frac{9}{10} = \frac{18}{30} = \frac{3}{5} \qquad\qquad \frac{3}{4}\div\frac{9}{8} = \frac{3}{4}\cdot\frac{8}{9} = \frac{24}{36} = \frac{2}{3}$$
Con números mixtos

Antes de multiplicar o dividir, conviértelos a fracción. Un error típico es multiplicar enteros con enteros y fracciones con fracciones: $2\tfrac{1}{2}\cdot 1\tfrac{1}{3}$ no es $2\tfrac{1}{6}$. Lo correcto es $\tfrac{5}{2}\cdot\tfrac{4}{3} = \tfrac{20}{6} = 3\tfrac{1}{3}$.

Decimales

De fracción a decimal

Divide el numerador entre el denominador. A veces la división termina y a veces una parte se repite para siempre (decimal periódico, se marca con una raya encima):

$$\frac{3}{8} = 0.375 \qquad\qquad \frac{2}{3} = 0.666\ldots = 0.\overline{6}$$

De decimal a fracción

Escribe el número sin punto sobre 10, 100, 1000… (tantos ceros como cifras decimales) y simplifica:

$$0.45 = \frac{45}{100} = \frac{9}{20} \qquad\qquad 1.25 = \frac{125}{100} = \frac{5}{4}$$

Operar con decimales

Multiplicar: multiplica como si no hubiera punto y, al final, el resultado lleva tantas cifras decimales como los dos factores juntos.

4
Ejemplo resuelto

Calcula $1.2\times 0.35$ y $4.5\div 0.15$.

Multiplicación: $12\times 35 = 420$. Los factores tienen $1 + 2 = 3$ decimales, así que el resultado es $0.420 = 0.42$.

División: recorre el punto del divisor hasta que sea entero y recorre el del dividendo los mismos lugares:

$$4.5\div 0.15 = 450\div 15 = 30$$
Para comparar

Si tienes que comparar fracciones con decimales, pasa todo a decimal. ¿Qué es mayor, $\tfrac{3}{5}$ o $0.58$? Como $\tfrac{3}{5} = 0.60$, la fracción es mayor.
